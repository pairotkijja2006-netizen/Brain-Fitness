# 🧠 Brain Fitness

**Strengthening minds. One game at a time.**

A Unity-based cognitive training application designed to support brain health among elderly individuals through three interactive memory-training games, gamified progression systems, and personalized performance tracking. The application was deployed at My Home Care Center in Bangkok, Thailand.

## 💡 Inspiration

Brain Fitness was inspired by my grandfather, who developed dementia. Seeing how cognitive decline affected his everyday life made me realize how easily we take our memory and cognitive abilities for granted. This personal experience motivated me to explore how I could use my passion for technology and game development to support elderly individuals facing similar challenges.

I recognized that traditional cognitive exercises could feel repetitive and unengaging, making it difficult for elderly individuals to participate consistently. I wanted to create an alternative that made exercising the brain feel less like a routine task and more like an enjoyable activity.

This led me to develop Brain Fitness, an application that combines interactive cognitive exercises with gamification, personalized performance tracking, and accessible game design. Beyond developing the software itself, I wanted to create something that could make a meaningful difference in people's everyday lives.

What started as a personal motivation to help my grandfather eventually grew into a project deployed at My Home Care Center in Bangkok, Thailand, allowing me to extend its impact to a wider elderly community.

## 🚀 Key Features

### Interactive Cognitive Training Games

Developed three interactive games targeting different cognitive abilities:

- **🎲 Dice Counting Game:** Challenges users to perform addition and subtraction using dice, strengthening numerical reasoning and mental arithmetic.
- **🧩 Shape Building Game:** Requires users to arrange shapes to match a target design, exercising visual recognition and spatial reasoning.
- **💰 Money Counting Game:** Simulates everyday financial calculations, reinforcing practical numerical and problem-solving skills.

### Gamified Progression System

Implemented gameplay mechanics designed to encourage consistent participation:

- Streak-based progression
- Performance-based reward points
- Competitive leaderboard
- Interactive cognitive challenges

### Player Profile Management

Developed a multi-user profile system that allows elderly users to:

- Create and delete individual player profiles.
- Access personalized gameplay records.
- Track individual performance independently.
- Return to existing profiles across gameplay sessions.

### Performance Tracking and Visualization

Implemented a statistics dashboard that visualizes individual gameplay performance over time, allowing users and caretakers to observe progress throughout their cognitive training sessions.

## 🧠 Technical Implementation

### Game Logic and Mechanics

Developed three distinct cognitive training games using C# and the Unity game engine.

Each game incorporates its own gameplay rules, user interaction mechanisms, and scoring logic to target different cognitive skills.

### Player Data Management

Designed a multi-user profile system to organize individual player information, gameplay statistics, and progression.

The system enables multiple users to interact with the same application while maintaining separate performance records.

### Performance Visualization

Implemented graphical representations of player statistics to communicate gameplay performance and progress in an accessible format.

The statistics dashboard allows users and caretakers to visualize changes in gameplay performance over time.

### Gamification Systems

Developed streak-tracking, reward, scoring, and leaderboard systems to encourage repeated engagement and provide users with measurable gameplay objectives.

### Accessible User Interface

Designed an elderly-friendly interface emphasizing:

- Simplified navigation
- Thai-language instructions
- Intuitive gameplay interactions
- Tablet-friendly controls
- Easily recognizable visual elements

## 🌍 Real-World Deployment

Brain Fitness was deployed at **My Home Care Center in Bangkok, Thailand**, where I collaborated directly with caretakers and elderly participants.

- Organized an introductory event for approximately 30 elderly individuals.
- Collaborated with caretakers to demonstrate gameplay and application navigation.
- Tracked the performance of six elderly participants through twice-weekly sessions over four weeks.
- Observed an approximately 10% improvement in measured memory-game performance among tracked participants.
- Donated three tablets to support continued access to the application.

These observations provided preliminary insights into user engagement and gameplay performance. They do not establish clinical effectiveness in preventing or delaying dementia.

## 🧪 Getting Started

### Playing the Application

1. Open [Brain Fitness](https://jiratip.itch.io/brain-fitness).
2. Click anywhere on the title screen to begin.
3. Create or select an existing player profile.
4. Select one of the three cognitive training games.
5. Complete gameplay challenges to earn points and build streaks.
6. Access the statistics dashboard to view gameplay performance and progress.

### Repository Information

This repository contains the WebGL build of the application for demonstration purposes.

The original Unity project source files are currently unavailable. As a result, the repository does not support rebuilding or modifying the original Unity project.
